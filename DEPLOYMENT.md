# Sanjeevani AI — Production Deployment Guide

This guide details the steps to deploy the Sanjeevani AI application, consisting of a **Next.js Frontend** (deployed to Vercel) and a **Python Flask Backend** (deployed to Render/Railway).

---

## 1. Deploying the Flask Backend (Render / Railway)

The backend handles the AI vision OCR models, edge-tts bilingual translations, and SQLite database storage.

### Steps for Render:
1. Create a new **Web Service** on [Render](https://render.com).
2. Connect your GitHub repository: `https://github.com/VanshSharmaPES/Sanjeevani`
3. Configure the service settings:
   * **Runtime:** `Python`
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `gunicorn server:app`
4. Set the following **Environment Variables** in the Render settings:
   * `GROQ_API_KEY`: *(Your Groq Cloud Vision API Key)*
   * `JWT_SECRET_KEY`: *(A long secure random string for signing JWT tokens)*
   * `FLASK_ENV`: `production`
   * `JWT_COOKIE_SECURE`: `True` *(Ensures session cookies are transmitted only over secure HTTPS)*
5. Once built, copy the public URL generated by Render (e.g. `https://sanjeevani-backend.onrender.com`).

### Initializing the Medicines Database:
Render container disk is writeable. To populate the 11,000+ medicine entries from the dataset, trigger the database import script on Render:
* Go to the **Shell** tab in your Render dashboard and run:
  ```bash
  python import_csv.py
  ```
* This will bulk-import the dataset into SQLite.

---

## 2. Deploying the Next.js Frontend (Vercel)

The Next.js frontend is deployed directly to Vercel and proxies requests to your deployed Flask backend.

### Steps for Vercel:
1. Log in to [Vercel](https://vercel.com) and click **Add New Project**.
2. Import your GitHub repository: `https://github.com/VanshSharmaPES/Sanjeevani`
3. Vercel automatically detects Next.js. In the **Environment Variables** section, add:
   * `PYTHON_API_URL`: *(The public URL of your deployed Flask backend, e.g. `https://sanjeevani-backend.onrender.com`)*
4. Click **Deploy**. Vercel will build and host the Next.js app in a few seconds.
